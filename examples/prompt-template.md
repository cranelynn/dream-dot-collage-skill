# Prompt Template

Use this template for one selected source photo at a time.

## Main prompt

Create one polished Dream Dot Collage from **only the supplied reference photo**. First isolate 2–5 recognizable elements from that photo using actual background removal or masks where available. Preserve original subject details, identity, pose, proportions, and colors. Each extracted element must have its own silhouette with the original background removed; a rectangular crop or the full photo inside a circle is not acceptable.

Design a travel-journal collage on a warm-white or cream background. Place one large circle with a flat solid-color interior. Arrange the isolated photo cutouts as separate elements within or around the circle, with clean white die-cut borders following each silhouette. Do not rebuild the original complete scene and do not add content from another reference photo.

Add a small minimal line-art sleeping puppy near the circle's lower edge. Add a few delicate hand-drawn orbit lines, stars, a moon, dots, or one small symbolic illustration. Optionally include one to three tiny handwritten labels, such as a place name or a short mood phrase. Keep the collage rich in small details but clearly art-directed, with varied scale, purposeful overlap, a controlled palette, and breathing room.

Output one finished portrait-friendly composition. If the current image model cannot preserve exact source pixels or remove backgrounds faithfully, do not pretend it has done so; use a masking/compositing tool where available or disclose the limitation.

## Negative prompt

No merging multiple reference photos, no full-photo circle fill, no rectangular photo panels, no original background left around a cutout, no circular crop passed off as extraction, no distorted faces or architecture, no invented source details, no forced purple palette, no heavy glow, no excessive glitter, no tangled lines, no cluttered sticker sheet, no large title, no watermark.

## Per-photo planning
- Source image: one image only.
- Main cutout: one recognizable element.
- Supporting cutouts: 1–4 elements from the same image.
- Solid circle color: choose to complement the source.
- Puppy placement: near or below the circle.
- Doodles/labels: only a few useful accents.

For a set of several photos, repeat the whole process separately for each photo. Never carry source content from one photo into another output.
