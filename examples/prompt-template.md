# Prompt Template

Use this as a starting point and adapt it to the single supplied reference image.

## Main prompt

Create one polished Dream Dot Collage using only the supplied reference image. Preserve the recognizable identity and defining visual features of its main subject. Select only 1–3 distinctive elements from this same image, isolate them as small independent photo cutouts, and use them as personal accents.

Build the composition around one large, clean circle with a flat solid-color interior. Keep the circle mostly empty; it is a graphic dream space, not a window into a photograph or a detailed scene. Add a small minimal line-art puppy sleeping peacefully near or partly overlapping the circle. Use a few delicate lines and a calm, compact pose.

Add at most 1–3 simple dream symbols, such as a candy, an origami crane, or a tiny star. Use a restrained palette informed by the reference, generous negative space, intentional asymmetry, delicate line work, and only very subtle paper texture if useful. Keep the photo cutouts recognizable and separate from the illustrated elements. The overall mood should be intimate, quiet, surreal, and thoughtfully art-directed.

Output one finished image with a clear focal hierarchy. No multi-panel layout.

## Negative prompt

Do not merge multiple reference images. No photo or scenic background inside the circle, no busy miniature world, no sticker-sheet layout, no random floating objects, no excessive stars or sparkles, no heavy glow or lens flare, no forced purple palette, no thick cartoon outlines, no over-detailed puppy, no distorted faces, no duplicated subjects, no invented source details, no clutter, no unrequested text, no watermark.

## Per-image adaptation notes

Before generation, fill in:

- Selected cutouts (1–3): [list]
- Circle color: [one solid color chosen to complement the source]
- Puppy placement: [near / below / overlapping circle edge]
- Symbol accents (0–3): [list only if they improve the composition]

Never carry these choices over from one reference image to another unless the user explicitly asks for a consistent series.
